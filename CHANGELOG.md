# Changelog

Notable changes to DevSwarm. For downloads, see [devswarm.ai/download](https://devswarm.ai/download). Full release notes are published on [GitHub Releases](https://github.com/devswarm-ai/devswarm/releases).

## v0.12.0 — Free Beta (2025-09-21)

- **Free beta**: DevSwarm Desktop is available at no cost while in beta.
- **Explorer / Editor mode**: view, explore, and edit files directly in DevSwarm.
- **Diff view**: review diffs and push to Git from within the app.
- **Improved multi-assistant support**: run multiple AI assistants side by side for faster exploration.
- **Branch isolation**: each assistant gets a clean, reviewable branch automatically.
- **Desktop builds**: available for macOS and Windows.
- **Feedback loop**: integrated issue tracking and discussions here on GitHub.
